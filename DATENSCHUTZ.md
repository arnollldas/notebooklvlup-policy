## 2. Überblick

NotebookLVLUP ist eine Chrome-Erweiterung, die ausschließlich auf deinem Gerät arbeitet. Es gibt **keinen eigenen Server**, **kein Benutzerkonto** und **keine Registrierung**. Alle gespeicherten Daten verbleiben lokal in deinem Browser.

---

## 3. Welche Daten werden gespeichert?

### 3.1 Lokale Browser-Daten (`chrome.storage.local`)

Folgende Daten werden ausschließlich lokal in deinem Browser gespeichert:

- **Gesammelte Links** (Capture-Modus): URLs, die du manuell per Mittelklick oder Strg+Klick markierst
- **Ordnerstruktur**: Name, Farbe, Emoji und enthaltene Notebooks deiner Ordner auf NotebookLM
- **Einstellungen**: Theme (Hell/Dunkel), Onboarding-Status

Diese Daten verlassen deinen Browser nicht. Sie werden nicht an externe Server übertragen.

### 3.2 Zugriff auf Webseiten

- **NotebookLM (notebooklm.google.com)**: Die Erweiterung liest die Notebook-Struktur aus und injiziert UI-Elemente (Ordner, PDF-Export-Button). Es werden keine Inhalte von NotebookLM gespeichert oder übertragen.
- **Alle anderen Webseiten**: Nur wenn der Capture-Modus aktiv ist, hebt die Erweiterung Links beim Hovern hervor. Es werden keine Seiteninhalte gelesen oder gespeichert.

## 4. Weitergabe an Dritte

Es findet **keine Weitergabe** von Daten an Dritte statt. Es werden keine Analyse-Tools, Tracking-Dienste oder externe APIs verwendet.

## 5. Deine Rechte (DSGVO)

Du hast das Recht auf:

- **Auskunft** über gespeicherte Daten
- **Löschung** aller gespeicherten Daten

Zum Löschen aller lokal gespeicherten Daten: Chrome → Einstellungen → Erweiterungen → NotebookLVLUP → Daten löschen. Alternativ kannst du die Erweiterung deinstallieren.
